# Portfolio de Sophie Bluel - Architecte d'intérieur

Code du projet 6 d'intégrateur web.

## Information pour le lancer le code

 - Lancer le backend depuis votre terminal en suivant les instruction du fichier ReadMe.
 - Si vous désirez afficher le code du backend et du frontend, faites le dans 2 instances de VSCode différentes pour éviter tout problème


## 🛠️ Fonctionnalités clés
* **Récupération dynamique des données** : Utilisation de `fetch` pour récupérer les projets et les catégories depuis l'API.
* **Filtres interactifs** : Mise en place de filtres par catégorie (Objets, Appartements, Hôtels & Restaurants) pour trier les projets en temps réel.
* **Espace Administrateur** : Création d'une page de login sécurisée pour accéder au mode édition.
* **Gestion du contenu (CRUD)** : 
    * Ajout de nouveaux travaux via un formulaire avec prévisualisation de l'image.
    * Suppression de projets existants via une modale de gestion.
    * Mise à jour instantanée de la galerie sans recharger la page.

## 🚀 Compétences techniques
* **JavaScript (ES6+)** : Manipulation avancée du DOM, gestion des événements, et programmation asynchrone (async/await).
* **Consommation d'API** : Requêtes GET, POST et DELETE via `fetch`.
* **Sécurité** : Gestion du jeton d'authentification (Token) stocké dans le `sessionStorage`.
* **UX/UI** : Création d'une fenêtre modale ergonomique pour l'administration des photos.
